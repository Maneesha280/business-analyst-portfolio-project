## 📝 Documents Included  

### **1️⃣ Business Requirements Document (BRD)**  
Defines the system’s purpose, scope, features, and functional requirements.

### **2️⃣ User Stories & Acceptance Criteria**  
Covers all user interactions:  
- Ticket creation  
- Categorization  
- Assignment  
- Status updates  
- Escalation  
- Dashboard viewing  

### **3️⃣ Process Flow Description**  
End‑to‑end workflow:  
Customer → Ticket Creation → Categorization → Assignment → Acknowledgment → Resolution → Escalation (optional) → Closure → Dashboard Reporting  

### **4️⃣ SQL Analysis Scripts**  
Includes queries for:  
- Ticket volume  
- Resolution time  
- Agent performance  
- Escalation rate  

### **5️⃣ Power BI Dashboard Description**  
Covers:  
- Ticket overview  
- Resolution performance  
- Agent efficiency  
- Escalation analysis
